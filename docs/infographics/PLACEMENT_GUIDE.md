# LP infographic placement guide

このZIPには、LPに埋め込む20点の画像を、**配置セクションごと**に整理して入れています。

## フォルダ構成
- `assets/hero/` : ヒーロー
- `assets/problems/` : 「こんな悩みはありませんか？」
- `assets/value/` : 「判断をそろえることで、現場も組織も動きやすくなる」
- `assets/theme/` : 「最初のテーマは浮腫」特集
- `assets/offer/` : 「提供内容」
- `assets/steps/` : 「導入は3ステップ」
- `assets/final-cta/` : 最終CTA
